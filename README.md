# Projecte-ESP32-PE: Desenvolupament d'un localitzador GPS
Projecte de Projectes d'Enginyeria (curs 25-26) amb l'objectiu de connectar una ESP32 a un sensor geolocalitzador i enviar les dades extretes per aquest a un servidor SENTILO.

****

### Autors:
* **Tomàs Lloret:** Representant, encarregat dels sensors
* **Eloi Belmonte:** Encarregat del server
* **Oriol Jiménez:** Encarregat del firmware

### Hardware:
* **ESP32**
* Sensor GPS **GY-GPS6MV2**
